# UMBRA

**UMBRA** es un videojuego de plataformas de precisión, puzles y sigilo en 2D desarrollado en **Unity**. El jugador controla a una criatura hecha de sombras que debe avanzar a través de entornos hostiles, utilizando la arquitectura del nivel para esconderse y sobrevivir a los haces de luz mortales que patrullan el escenario.

El proyecto utiliza el pipeline gráfico **URP (Universal Render Pipeline)** para la gestión de iluminación 2D procedural y el paquete **UI Toolkit** para interfaces modernas y desacopladas.
